# 西兰公园 · 照片提示词分析与生成

上传参考照片，逐张分析画面、生成提示词，并进行两轮生成和对比优化。

## 安装

在豆包电脑端发送：

```text
豆包你好，帮我安装 GitHub 上 zihengl400-spec/xilan-photo-prompt-analysis 的技能。
```

## 使用

上传一张或多张参考图，发送：

```text
请使用西兰公园的照片提示词分析与生成技能，逐张分析这些照片，完成两轮生成和对比优化。
```

每张图依次完成：分析照片、编写完整提示词、生成初版、对照原图优化提示词、生成第二版。默认竖版 3:4。仅需分析时可说明“只分析，不生成图片”。

完成后，上传自己的照片并发送：

```text
请用我的照片做同款，使用刚才优化后的提示词。
```

技能会将完整优化提示词与身份保留要求结合，以你上传的照片作为人物身份参考生成同款。多张参考图时，请同时注明使用哪一张。生成效果取决于客户端和模型，人物相似度不能保证。

生成依赖豆包当前环境中指定的图片生成能力；若不可用，技能会说明情况并停止，不会自动切换型号。安装和调用情况以客户端实际能力为准。
